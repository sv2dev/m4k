# Changelog

All notable changes to `@m4k/common` are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.10]

### Added

- `classify` and `discard` image options, `InlineClassification`, `invalidInlineClassification` and `isValidClassificationResult`.

## [0.2.9]

### Added

- Added the versioned image-classification contract, candidate validation and input-bound results.
- Added Unicode-safe option encoding and embedded-preview image options.

## [0.2.8]

### Changed

- Updated the TypeScript development dependency.
